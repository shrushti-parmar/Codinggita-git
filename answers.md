1. What is the difference between git clone and git init?

Ans: Git clone creates a local copy of an existing remote repository, while Git init creates a new git repository in the current directory.

2. What does git status tell you?

Ans: It tells which files are tracked or untracked, which files are staged or unstaged, which files are modified, changes to be committed.

3. What is the purpose of git add?

Ans: It stages all changes.

4. What is the difference between git diff and git diff --staged?
Ans: Git diff shows changes in the working directory that have not been staged and git diff --staged shows changes currently in the staging area.

5. What is the purpose of git commit?
   
Ans: Commit records all the changes along with information such as author,time,commit message,etc.

7. What is the difference between git log and git log --oneline?
   
Ans: Git log gives all the history while git log --oneline gives a shorter history.

9. What information can you see using git show?
    
Ans: It shows information about recent commit, it shows author, commit Id,date, commit changes.

11. What does git pull do?
    
Ans: It brings changes from a remote repository into your local repository.

13. What does git push do?

Ans: It brings changes from a local repository into remote repository.

13. What is a Git branch?

Ans: Git branches allow developers to work on different features or changes without directly modifying the main development branch.
